# Separate resource inventory

resources-manifest.json records the files in the separate playable release for Hair Gradient 0.3.3. Paths are relative to that extracted release, not to this source repository. Only names, sizes and hashes are included. Verify with `python verify.py --mod-root <release-root>`.

Resource bytes and third-party models are outside this source export. A source-code license or successful hash check does not license underlying game assets. Model provenance remains documented in the separate playable release credits. The absence of assets here does not imply that they can be rebuilt from the DLL source.

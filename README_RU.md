# Hair Gradient — исходники 0.3.3

Это самостоятельный проект для GitHub: загрузите содержимое распакованного архива в корень отдельного репозитория. Рабочие файлы игры менять не нужно.

Сборка DLL и тестов: Windows x64, PowerShell, Zig 0.13.0. MinHook и его лицензия уже включены. Установленная игра и второй мод для сборки не нужны.

```powershell
./build.ps1 -ZigExe "C:/Tools/zig/zig.exe" -Test
```

Результат: `out/hair_gradient.dll`. Описание кода и проверки соответствия версии — в README.md и release-manifest.json. Проверка контрольных сумм: `python verify.py`.

В архиве нет DLL, моделей, текстур, игровых архивов, сохранений и личной истории разработки. Для готовых ресурсов приложены только список, размеры и SHA-256. В GitHub не добавляйте папку out, игровые файлы и входные данные шейдеров; для них настроен .gitignore. Каждый из двух модов публикуется отдельно.

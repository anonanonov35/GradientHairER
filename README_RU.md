# Hair Gradient — исходники для GitHub

Автор: **AnonAnonov**, версия пакета **0.3.2**.

Распакуйте архив и загрузите его содержимое в корень своего репозитория GitHub. Отдельный архив мода `HairGradient-0.3.2.zip` можно прикрепить к GitHub Release. Сам архив исходников не является установленным модом.

Для сборки DLL нужен Windows x64 и Zig 0.13.0. MinHook уже включён с лицензией и зафиксированной версией. Запустите:

```powershell
./build.ps1 -ZigExe "путь/к/zig.exe" -Test
```

Результат — `out/hair_gradient.dll`; также выполняются шесть нативных тестов без запуска игры. Для сборки DLL игровые файлы не нужны. Исходники работы с шейдерами находятся в `shader-tools`: их сборка требует отдельно извлечённых из своей игры оригинальных ресурсов. Готовые игровые шейдеры в архив исходников не включены.

Для поддержки приложите ссылку на репозиторий и архив мода. В `RELEASE_HASHES.json` записаны контрольные суммы опубликованного пакета, DLL и двух шейдеров. Пересобранный DLL может отличаться побайтно из-за среды и путей сборки; автоматические тесты не означают сертификацию антивирусом.

В 0.3.2 изменены только конфиг, документация и упаковка: DLL и шейдеры сохранены из 0.3.1. Проверка в игре относится к принятой основе; финальное автоопределение UmaEars проверено нативными тестами. Отображение на скачанной причёске, 1.17.1 и Convergence пока не проверены. Подробная карта кода, поведение DLL, зависимости и границы проверки описаны в английском `README.md`.
